## Apple Health Pro v8.8.0

本次更新带来更简洁的界面、macOS 原生玻璃材质，以及保留原始记录的流式导出引擎。

- **更自然的外观**：恢复资源占用圆环和进度配色；macOS 26+ Liquid Glass；启动跟随系统，点击右上角图标直接切换深浅色。
- **更简洁的操作**：原生 ZIP / 文件夹选择面板、紧凑日期弹窗、胶囊导出按钮；减少常驻说明文字。
- **更完整的记录**：保留起止时间与时区，补充运动统计，未知类型单独保留。
- **更可靠的导出**：两遍流式处理、严格输入校验、可取消任务、独立结果目录、失败清理与 SHA-256 清单。
- **本地处理**：健康数据不会上传；默认开启来源名称匿名化和 Excel 安全文本。

### 数据说明

导出保留多来源原始记录，不复现 Apple 健康的来源优先级或去重，不应直接跨来源累加。日期范围按记录起始时间的原时区自然日筛选。来源名称匿名化不等同于健康数据完全去标识化。

CSV 前五列保持原有顺序，新增结束时间、记录种类、运动时长与详情字段；输出均采用 `类别_Part001.csv` 分片编号。ECG、路线、临床附件及自由文本元数据不在本版输出范围。
