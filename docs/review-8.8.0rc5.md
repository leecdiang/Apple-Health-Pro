# 8.8.0rc5 深色玻璃同步修正

针对 rc4 从浅色切换深色后玻璃栏泛白、白字对比度不足的实机反馈。

## 修正

原实现只更新 Qt 调色板和 NSGlassEffectView 外观，未同步 NSWindow / 根 NSView；原生标题栏及窗口合成仍可能保留浅色。现在主题切换在同一轮 UI 更新中同步窗口、根视图和玻璃。

- 手动浅色/深色明确设置窗口外观；选择“跟随系统”时移除原生外观覆盖。
- 深浅切换时重新创建玻璃合成视图，避免保留上一主题的合成状态；普通采样、布局刷新不重建。
- 深色玻璃添加低透明度中性深色色调，改善亮背景下 Qt 白字可读性；浅色清除该 tint，保留原生玻璃。
- 对旧版未重编译本机适配库的加载失败增加回退处理。

## 验证

- 53 项测试通过。新增测试验证原生窗口同步、连续切换时的玻璃重建、普通刷新不重建及关闭释放。
- 冻结应用导入/导出 217 条合成记录通过。
- 本机 Cocoa 原生 smoke 完成 9 个检查状态：浅→深→浅→深→浅→深→跟随系统→无障碍实色→深色。每次原生窗口、玻璃 effectiveAppearance、tint 状态和几何校验通过，最终资源释放通过。
- 独立合成数据窗口验证从浅色进入深色的实际画面：标题栏与玻璃同步变深，未出现此前的亮灰色整片玻璃。
- ARM64 构建及 ad-hoc 签名验证通过；尚未发布 Release。原用户加载真实健康数据的 rc4 窗口保留，未用来自动导出或执行测试。
