# 8.8.0rc4 交互与样式修正

基于用户对 rc3 的五项实机反馈修正。本轮只构建本地审核包，未发布远端 Release。

- 导出按钮：使用 QAbstractButton 自绘胶囊，圆角按实际高度计算；摆脱 macOS 样式对 QPushButton 固定高度和禁用样式的覆盖。浅/深色、启用/禁用均验证透明圆角像素。
- ZIP 与输出位置：macOS 调用 AppKit NSOpenPanel 原生 sheet。通过 UTTypeZIP 过滤，异步回调由 Qt 主线程接续；取消不会替换现有输入。中文文件名、大写 .ZIP 已在真实原生面板中选择并导入 217 条合成记录。
- 进度圆环：移除虚线外框。鼠标交互不显示外框；键盘 Tab 导航时提供低对比度实线光环，保留可见焦点与空格/回车导入。
- 重叠指标：从主视图移除提示条。详情中说明不同来源可能记录了相同指标、导出不自动去重且不能直接累加；数据和清单行为不变。
- 日期：替换默认 Qt 日历和红色表头，使用圆角弹层、年月选择、简洁周标题与圆形日期选中态。支持跨月/跨年、闰日、方向键、PageUp/PageDown、回车确认和 Escape 取消。日期倒置仍会阻止导出。

## 验证

52 项测试通过，包括原有数据与任务生命周期测试，以及按钮圆角像素、日历闰日与键盘跨月、取消不改日期、焦点显示、详情展开及原生回调取消。macOS ARM64 应用构建与 ad-hoc 签名校验通过；冻结应用合成数据导入导出 smoke 通过。原生面板实测 ZIP 导入通过。

原生文件选择采用 Apple 公共 NSOpenPanel / UTType API，不依赖旧 Qt 非原生文件对话框；其他平台走 Qt 的系统文件面板。日历是统一设计的自定义 Qt 面板，不声称是 AppKit 日期控件。未运行 Windows/Linux 实机验证，未进行 Developer ID 公证。
